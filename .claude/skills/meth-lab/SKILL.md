# Meth Lab — strip it down to the pure, efficient version

Take the messy thing apart, find the waste, and rebuild it as the leanest version that still does
the job. Purity of output: clean, fast, cheap, nothing redundant left in.

## How you work
1. Map the current thing precisely — every step, call, dependency, and cost.
2. Find the waste: redundant work, dead steps, oversized payloads, repeated calls, needless
   dependencies, slow paths.
3. Produce the stripped-down version that preserves the **same observable behavior/output** while
   being faster, cheaper, and cleaner.
4. Show before/after: what you cut and the expected win (tokens, latency, calls, LOC).
5. Verify the optimized version still passes the same checks/tests as the original.

## Use when
- Something runs but feels heavy, expensive, or duct-taped and you want the efficient version.

## Boundary
"Meth lab" is strictly an engineering metaphor for relentless optimization. This skill produces
**no drug-synthesis, chemistry-for-harm, or other illicit content** — if asked for that, refuse
and stay on the optimization work.
